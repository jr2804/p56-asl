# AGENTS.md — docs/

## Purpose

User-facing documentation site for p56-asl, built with MkDocs Material and
deployed to GitHub Pages. This file is the local contract for authoring,
math, figures, and verification of everything under `docs/`.

## Ownership

- `docs/` — all site content (Markdown pages, committed figures, CSS/JS).
- `mkdocs.yml` — site config: nav, theme, extensions, plugins, deploy URL.
- `.github/workflows/docs.yml` — auto-deploy to Pages on push to `main`.
- `scripts/gen_*.py` — generators for committed figures (e.g.
  `gen_extended_mode_figure.py` → `docs/reference/extended-mode.svg`).
- `.config/mise/conf.d/docs.toml` — `docs`, `docs-serve`, `docs-deploy` tasks.

## Local Contracts

### Toolchain

- Build: `mise docs` (= `uv run mkdocs build --strict`). Strict mode fails on
  broken links, missing nav entries, and config warnings — keep it green.
- Serve: `mise docs-serve` (`mkdocs serve`, live reload).
- Deploy: push to `main` triggers `.github/workflows/docs.yml`; the site
  lands at `https://jr2804.github.io/p56-asl/`.
- Do NOT use zensical — it was removed (Windows watcher panic). mkdocs is
  the only documentation tool.

### Markdown style

- One page per topic under `docs/`; every page must be listed in the `nav`
  section of `mkdocs.yml`.
- Frontmatter: `---\ntitle: <Page Title>\n---` (see existing pages).
- Include external files with pymdownx.snippets: `--8<-- "README.md"`
  (paths resolve from the repo root). Used by `index.md`, `credits.md`,
  `license.md`.
- Executable examples: fenced block with `python exec="yes"` (markdown-exec),
  e.g. `credits.md` runs `scripts/gen_credits.py`.

### Math style

- **Inline math**: `$...$` (e.g. `$c_j$`). Rendered as `\(...\)` by
  pymdownx.arithmatex (`generic: true`).
- **Display math**: ` ```math ` fenced blocks — NOT `$$...$$`. The `$$`
  delimiters are brittle inside list items (pymdownx's block-math heuristic
  fails when the closing `$$` is followed by a list item without a blank
  line). The ` ```math ` fence is robust everywhere (lists, tables, prose).
- MathJax 3 is loaded from CDN via `extra_javascript`; its defaults already
  recognize `\(...\)` / `\[...\]`. No custom JS config or CSS hiding rules
  — a `visibility: hidden` rule on `.arithmatex` previously hid all math
  permanently (MathJax never adds `.mjx-math` to the parent).
- Keep formulas to KaTeX/MathJax-supported TeX: `\mathrm`, `\text`,
  `\frac`, `\log_{10}`, `\max`, `\qquad` are fine.

### Figures

- Committed figures live next to their page (e.g.
  `docs/reference/extended-mode.svg`), generated by a script under
  `scripts/` so they are reproducible: `uv run python scripts/gen_*.py`.
- Reference from Markdown with a relative path:
  `![alt text](extended-mode.svg)`.
- Do not commit ad-hoc plots; regenerate from the script.

## Work Guidance

- When adding a page: write it, add it to `mkdocs.yml` `nav`, build with
  `mise docs` (strict) to catch link/nav errors.
- When changing math: prefer ` ```math ` for display, `$...$` for inline;
  verify the rendered HTML contains `class="arithmatex"` blocks (not
  `<pre><code>`).
- When changing the toolchain or deploy: update this file, `.agents/FILES.md`
  (docs row), and `.agents/ONBOARDING.md` (layout bullet) as needed.

## Verification

```bash
mise docs          # strict build — must pass
mise format-md     # rumdl over docs/ (MD033 disabled: inline HTML allowed)
```

- `mise docs` must complete with zero warnings in strict mode.
- `mise format-md` must be clean before committing Markdown changes.
